# Smart Meter Monitoring System ⚡

## Features

- Meter Event Tracking
- Tampering Detection
- User Dashboard (Usage + Bill Prediction)
- Employee Dashboard (Reports)

## Tech Stack

- Frontend: React
- Backend: FastAPI
- Database: SQL

## Run Locally

### Backend

cd backend
uvicorn main:app --reload

### Frontend

cd frontend/client
npm install
npm start
